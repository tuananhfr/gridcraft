# ERPCons changes

- Both: emulate read-only DAO queries through explicit MDB selection and AutoCAD drawing commands as DXF exports; OS focus and current-directory calls are logged no-ops.

- Both: enable cooperative macro running on web with persisted time limits (5 s web, 30 s desktop defaults), local run times and duration, event-only consent notices and precise refusal locations.

- (desktop) Run VBA macros and assigned Form Control buttons from Macro with session consent, responsive Stop, interactive prompts, rollback diagnostics, run logs and a configurable time limit.

- Both: add consent-gated Excel VBA engine bindings, cooperative macro execution with cancellation and atomic undo/rollback, headless dialog defaults and session run logs; unsupported compatibility levels are refused and no open/event macros run automatically.

- Both: keep the Macro procedure list in a stable clipped viewport when viewing source, and show translated coloured compatibility level badges.

- Both: add cached read-only VBA analysis, procedure compatibility and source browsing in Macro, and precise VBA UDF Error Checking with CLI udfUnavailable counts (GRID-08).

- Both: add the sandboxed gridcraft-vbarun VBA language interpreter with host hooks, injectable clock, runtime limits and synthetic language tests; no Excel object bindings or automatic macro execution.

- (desktop) Attach a deterministic CycloneDX 1.5 Cargo dependency SBOM to each desktop release and include it in SHA256SUMS.

- (web) Report per-document draft revisions and asynchronous checkpoint outcomes to the ERPCons shell v2 bridge.

- Both: add the `gridcraft-vba` crate, a bounded read-only MS-OVBA project analysis (modules, procedures, UDFs, events, references, protection flags, compatibility levels 1-4) that never executes VBA (GRID-08 groundwork; not wired into the UI yet).

- (desktop) Repository variable `ERPCONS_SKIP_MACOS=true` releases Windows and Linux installers without waiting for a macOS runner; update.json then lists no Mac asset.

- Both: add sandboxed Jet 3/4 Access table reading, R2000 DXF drawing output and the undoable `data.importAccess` command for future ETABS VBA bindings.

- Both: add scoped sheet/selection calculation and Manual cache deferral, report calculation errors and translated diagnostics/import notices without executing VBA, reject erroneous CLI checks, and provide disabled 44-point Undo/Redo controls with transaction IDs/timestamps, grouped range edits and save-preserved history. A typed formula that cannot be parsed shows #NAME? again (only a cached file value is kept).

- Both: GRID-02 marks unreadable formulas and their dependents as not calculated while retaining cached values, with translated grid diagnostics and Error Checking notices; GRID-10 preserves legacy .xls VBA projects when saving as .xlsm and warns about unconverted macro buttons.

- Point the website links (About, installers, release notes) to https://office.erpcons.ai; app ids keep the `vn.erpcons.*` form.
- (desktop) Add signed self-updates with automatic checks, translated Help notices, save-before-update guards, download cancellation and retry, and Windows installation permission guidance; MSI updates wait for Install now or Cancel.

- (desktop) Use the ERPCons app icon for macOS document types and offer XLSB/ODS imports in Windows Default apps alongside the existing file associations.

- (desktop) Add tag-validated GitHub Actions builds for unsigned Windows, Linux and ad-hoc signed universal macOS installers, fixed download names, SHA-256 checksums and Vietnamese release notes.

- (desktop) Brand the app and installers as Bảng tính – ERPCons, isolate settings under ERPCons/BangTinh, and ship contributor-original ERPCons icons while preserving web identity.

- Desktop recovery: atomically store unsaved workbook drafts in per-instance directories with separate lifetime lock files, recover only after their owner exits (10 documents, 64 MiB), restore them unsaved with recovery labels, preserve macros, and AutoSave .xlsx/.xlsm case-insensitively.
- Desktop file filters follow the current UI language; translate the edited window title suffix.
- Desktop Save As offers macro-enabled templates (.xltm) first when suggested.

- Both: GRID-03 keeps `.xlsm`/`.xltm` VBA signature parts (signature, Agile, V3) byte-identical behind a SHA-256 guard of the VBA project, reports lost signatures and macros (.xls signatures, stale or unkeepable parts, non-macro formats) through one `io::save_warnings` shared by Save, Save As, AutoSave/drafts, exports, web download, CLI and MCP, and lists Form Control/ActiveX buttons from VML, ctrlProps, ActiveX parts and .xls OBJ records without running macros or changing button write-back.

- Desktop: default to Vietnamese when no UI language is saved, respect saved languages, and atomically save language changes immediately with logged write errors.
- Both: G5-debt shows a translated, dismissible circular-reference notice after an edit creates #CIRC! or a workbook containing it opens, without changing cell errors or saved formats or repeating during recalculation.
- Both: G5-debt translates generated PivotTable Row Labels, Column Labels, Grand Total, Values and Total captions at grid display time; Vietnamese uses Nhãn hàng, Nhãn cột, Tổng cộng and Giá trị while source items, stored cells and XLSX retain their original text.
- Both: G5-debt replaces the English product name with Bảng tính in Vietnamese catalog values, updates exact-message regressions and guards the entire Vietnamese catalog against leftover GridCraft values; English keys and other languages retain their names.
- Both: G4-legacy identifies .xls names and OLE2 content independently of the extension, shows one translated import or refusal dialog, and keeps legacy imports on the existing .xlsx Save/Save As path so the original .xls cannot be overwritten with OOXML bytes.
- Both: G4-legacy reuses the dismissible open notice bar for substituted workbook fonts after discovery and binding, lists at most three distinct names plus the remaining count, preserves other open warnings, and notifies only once per opened workbook; all interface catalogs include the new messages.
- Both: L-G CSV/TSV file exports prefix executable text (including text formula results) with an apostrophe while preserving typed numbers/dates and clipboard copy; the single CSV UTF-8 format includes a BOM for Vietnamese in Excel and is labelled accordingly. Import strips the BOM but keeps literal apostrophes, including export safety prefixes.
- Both: G3 external Paste Special offers Keep Source Formatting, Match Destination Formatting and Values Only on desktop and web, with Vietnamese labels; destination modes omit source styles and merges, pasted vi-VN formulas use regional separators, and engine regression coverage includes deterministic XLSX XML assertions for rich HTML paste.
- Both: G2 richer HTML clipboard tables preserve typed numbers/text, supported inline and tag/class CSS, number formats and two-dimensional merges; hidden content is skipped, HTML imports fall back to plain text beyond 8 MiB / 20,000 cells / 64 levels / 8 KiB inline styles, copy exports real per-side borders and numeric attributes, and covered merge cells stay empty in clipboard text and TSV files.
- Web: a capture-phase clipboard bridge carries HTML, plain text, RTF and bounded images into one paste event, reads the system clipboard from Paste buttons and menus, and writes HTML plus text together on copy/cut without a later text write replacing the HTML. Browser read/write failures and oversized parts show translated notices (Vietnamese and English).
- Both: `edit.paste` uses values from the existing HTML table parser when supplied (falling back to text without a table or past the 8 MiB, 20,000-cell including column spans, or 64-level nesting limits, checked before parsing in `clipboard_limits.rs`); matching same-session copy text, including browser CRLF line endings, retains the engine clipboard's formulas and styles even when external HTML is stale. HTML style/merge parsing and Paste Special are unchanged.

- Removed the ArtCraft logos and marks (`docs/brand/`) and the links to the ArtCraft Discord and getartcraft.com from the About dialog and README, as the ArtCraft brand terms require for forks.
- About now reads "ERPCons Văn phòng — dựa trên GridCraft của nhóm ArtCraft. MIT OR Apache-2.0." and links this fork's source.
- Builds with `CRAFT_FONTS_DIR` (all ERPCons releases, web and native) embed Inter Regular/Bold (OFL-1.1) from [craft-fonts](https://github.com/storytold/craft-fonts) at `43913056` (`crates/ui-egui/build.rs`); it is appended after the primary face of every font family (after egui's monospace font for MONO), so Vietnamese renders where no system font can be loaded. `craft-fonts-ref` in `release.yml` and `.cargo/config.toml` point at that checkout.
- Print and PDF export keep Vietnamese: `gridcraft-pdf` can embed a Unicode TrueType font (Type0 / CIDFontType2, Identity-H, whole-file FontFile2, ToUnicode; `crates/pdf/src/unicode.rs`). A string WinAnsiEncoding can't carry is drawn and measured in it (bold for bold styles; italic uses the upright face); other strings keep the standard 14 fonts, byte for byte. The app registers the bundled Inter Regular/Bold at startup (`SheetApp::new`); without craft-fonts, or in the CLI/MCP, nothing is registered and PDFs are as before.
- Web: closing or reloading the tab with unsaved changes asks first (`beforeunload` in `apps/gridcraft-web/src/web.rs`). Not in `?host=parent` mode, where the parent page hears `gridcraft:dirty` and guards leaving.
- Web: Save clears the unsaved-changes state once the browser has the file: `Services::download` takes a `DeliveryReport` the shell settles (written through the save picker, or an anchor download started) and the workbook counts as saved as of the bytes written (`Session::mark_saved`), so edits made while the picker is open stay unsaved. A cancelled picker leaves it unsaved; a failed save also says why.
- Web: unsaved workbooks are drafted to the ERPCons office shell's `window.erpDrafts` (`put`/`remove`/`ready`, which stores them and owns all recovery UI), as XLSX, once 2.5 s idle (30 s checkpoint while editing continues, spaced by 10× the last encoding time) and right away when the page is hidden; the draft is removed once the workbook is saved or closed. A recovered draft reopens unsaved under its name and keeps its key. Timing is `crates/ui-egui/src/drafts.rs`, the bridge `apps/gridcraft-web/src/drafts.rs`. Off without the shell and in `?host=parent` mode; workbooks opened with their password are never drafted (GridCraft can't encrypt).
- Vietnamese interface (`crates/ui-egui/src/i18n/vi.rs`, `Language::Vi`), translated clean-room with Office-style Vietnamese tab, group and command names (feature names only). The status bar, sheet tab menu, task panes and colour palette labels now go through the translations. The web build opens in Vietnamese unless the user picked another language and remembers the choice in `localStorage` key `erpcons-ui-language`, which the other ERPCons editors share (`apps/gridcraft-web/src/language.rs`); a CJK choice falls back to Vietnamese there, as the web build bundles no CJK font.
- `now_ms()` reads the browser clock on the web (it returned 0, so toasts never cleared and any two clicks on a cell counted as a double-click).
- Keyboard shortcuts: F1 opens a Keyboard Shortcuts dialog listing every grid shortcut (Windows notation) with its label in the interface language, searchable by label (translated or English) or keys; the list (`keymap::reference`) is tested against the real key dispatch. F4 outside the cell editor repeats the last formatting, border, fill, number format, insert/delete or clear action on the current selection (`edit.repeat`, which keeps the action in `Session::last_repeatable` and drops its range so it applies to whatever is selected; any other edit clears it); in the cell editor F4 still cycles `$` anchors. Ctrl+Y repeats when there is nothing to redo, as in Excel.
- Document tabs: with two or more workbooks open, a strip under the title bar shows one tab per workbook (title cut with "…" and shown whole on hover, a dot for unsaved changes, × to close; middle-click also closes). Clicking a tab switches through `window.activate`; × closes through `file.close` (which now takes an `index`), so an unsaved workbook still asks first, and closing another tab keeps the one in front. Windows hidden with View ▸ Hide get no tab and stay hidden when another window closes. At most 10 workbooks can be open (`MAX_DOCUMENTS`): New, Open, drag-and-drop, recovered drafts and New Window refuse an eleventh with a translated message.
- Regional format (File ▸ Options ▸ General, `app.region.set`, `UiState::region`): a setting of its own that follows the interface language until chosen (Vietnamese → vi-VN, Spanish → the Spanish entry it had, otherwise en-US), saved in `ui.json` on desktop and in `localStorage` key `erpcons-grid-region` on the web. In vi-VN, formulas keep English function names with `;` between arguments, `,` as the decimal point and `\` between array columns (`=SUM(1,5;2,25)`, `{1;3}`), and the formula bar redraws stored formulas in the chosen notation; typed numbers group with `.` (`1.234` is 1234, `1.234,5` is 1234.5), dates are day first (`19/10/2026`, `19/10` in the current year, `19-10-2026`), and `1.000.000 ₫` / `1.000.000đ` / `1.000.000 VND` become numbers formatted `#,##0 [$₫-42A]`; editing a cell shows its number or date in the same notation. The Accounting Number Format button applies the region's currency (₫ in vi-VN, `_-* #,##0 [$₫-42A]_-;…`) and its menu offers ₫. Files, `cell.set` without `region`, and stored formulas stay en-US; `TEXT()` stays en-US.
- Values are displayed in the regional format (`numfmt::format_value_in`, `display::*_in`, `Session::region`, which the app keeps in step): in vi-VN a format code's `.` and `,` show as `,` and `.` (`#,##0.00` shows `1.234,50`, General `1234,5`, `12,5%`, `1,23E+04`), the built-in short date (id 14, `m/d/yyyy`) and id 22 show day first (`19/10/2026`, `19/10/2026 13:30`) and `[$-F800]` long dates as `19 tháng 10 2026`, while explicit codes such as `mm/dd/yyyy` show as written; `mmm`/`mmmm`/`ddd`/`dddd` are `thg 10`/`tháng 10`/`T2`/`Thứ Hai` (CLDR `vi`). This covers the grid, the status bar sums, printing, print preview, Page Layout headers (`&D`) and PDF export (`region` param), charts (axes, data labels, categories), slicer tiles and filter lists (captions only: filter values and files stay en-US), Find (matches what is shown), the Number Format menu and Format Cells sample, and Ctrl+; / Ctrl+Shift+". Copied text follows the region and pasted text is read in it, like typing; CSV, web page export and XLSX stay en-US, as do `TEXT()`, `VALUE()`/`DATEVALUE()` and data returned to agents. In vi-VN the Currency and Accounting categories apply ₫ (`#,##0 [$₫-42A]`, the ₫ accounting code). Spanish keeps the en-US display.
- Opening a package (XLSX, XLSM, XLSB, ODS, also inside an encrypted workbook) checks what actually inflates, never trusting the sizes the zip headers declare: an entry inflating more than 200:1 once past 4 MiB, an entry or a package over its cap (already when a header declares it), or too many entries refuses the whole file, even when the part was optional, with "The file is too large or abnormally compressed, so it can't be opened." ("Tệp quá lớn hoặc bị nén bất thường nên không mở được."). The limits live in `crates/xlsx/src/limits.rs`: desktop keeps 512 MiB per entry, 1 GiB per package and 200,000 entries; the web build allows 256 MiB, 512 MiB and 50,000. Reading grows its buffer with `try_reserve`, so a failed allocation is that error rather than a crashed tab.
- `deny.toml`: a cargo-deny policy matching PdfCraft's (permissive licences only, crates.io plus the pinned craft-libs revision as the only sources, no wildcard requirements, RustSec advisories with a written reason for each ignore). Run with `cargo deny check`.
- Phones and tablets: below `NARROW_WIDTH` (600 points of window width; a tablet in portrait stays wide, `crates/ui-egui/src/narrow.rs`) the ribbon folds to its tab row once as the window crosses the breakpoint; the user can open it again and that holds until the window widens, which brings back the wide-window choice (also what `ui.json` saves meanwhile, `SheetApp::saved_ui`). The ribbon's tab row scrolls sideways (finger drag or wheel). Task panes and the PivotTable Fields pane float over the sheet when narrow instead of squeezing it. On a touch screen (`crates/ui-egui/src/touch.rs`, mouse and pen unchanged): a one-finger drag pans the sheet (with a short fling when animations are on; two fingers pinch-zoom), a tap selects, a double tap edits, a long press opens the cell or header menu, and a round handle on the selection's bottom-right corner drags out a range; a drag over a chart pans unless the chart is already selected. The fill handle and drag-to-move a selection stay mouse-only. When narrow, the title bar drops its optional controls lowest priority first (AutoSave label, theme switch, Comments, Home, undo list, the Share label, Redo; `crates/ui-egui/src/title_fit.rs`) and elides the workbook title into the room left; the status bar keeps, in order, the zoom buttons, Sum, the view buttons, Count, Average and the zoom slider as they fit, and leaves out a note on the left that would run into them; the PivotTable Fields pane gets a close button and stays closed until the active cell leaves that pivot.
- The "can't open" errors for a broken or refused file (not a valid zip package or spreadsheet, invalid XML, a missing workbook part, an ODS without sheets, a legacy binary that isn't a workbook, a damaged or unsupported encrypted file, a wrong password) show in the interface language: the message box matches them against the engine's English templates and translates the reason inside (`Language::tr_message`, `crates/ui-egui/src/i18n/messages.rs`), Vietnamese included; the engine, CLI and agents keep the English text. The PivotTable Fields pane wraps its Refresh / Calculated Field… / Report Layout row instead of clipping it, and Report Layout is a menu button so it can move to the next row (`pivot_pane.rs`).
- Large workbooks: web drafts are written with the fastest deflate (`drafts::draft_bytes` → `io::save_xlsx_fast`, `gridcraft_xlsx::Packing::Fast`): the same parts as Save, about two thirds larger, read back only by GridCraft, which halves the time a draft of a 45 MB workbook blocks the page (6.4 → 3.1 s natively); Save and Ctrl+S output is unchanged byte for byte, and drafts stay paced by 10× their last encoding time. `file.open` is journaled without the file it carries as `base64` (`cmd::journal_entry_params`), so an opened file no longer stays in the session journal (60 MB of text for that workbook) or in a recorded script; a dropped file's base64 is moved into the command instead of copied, and base64 decoding uses a lookup table (0.6 → 0.14 s for 45 MB).
- Documents closed in a session are kept (`crates/ui-egui/src/closed_docs.rs`: the ten most recent, 64 MiB at most, oldest dropped first, as the bytes a draft writes; never one opened with its password) and Reopen Closed Document (`file.reopenClosed`; the tab strip's right-click menu; File › Open; no shortcut) brings the last one back as a new tab under its name, unsaved if it was closed with Don't Save, within the 10-document limit. Ctrl+Shift+T stays AutoSum. The tab strip's menu also has Close Others and Close All, and closing the desktop window asks too: one dialog lists every unsaved document with Save All / Don't Save / Cancel (`close_many.rs`); Save All saves them one after another, each finishing before the next, and closes them once all are saved. On the web each browser save picker needs a click of its own, so after one has written its file the dialog stays up, that row reads “— Saved” (“— Đã lưu”), and the main button becomes Save “<next name>” (Lưu “…”) for the next picker; while a picker is open its row reads “— Saving…”, Save and Don't Save are disabled and Cancel stays enabled. Browsers without a save picker (Firefox, Safari) still download them all in one click. A cancelled or failed save, or Cancel while a picker is open, stops the rest and closes nothing; Cancel closes nothing; `app.quit` from the control channel still quits without asking. The status bar shows "Saving…" ("Đang lưu…") while a save is in flight (the web save picker; desktop writes are synchronous and show no in-flight state) and "Save failed" ("Lưu không thành công", reason on hover and click) until the next successful save or edit (`save_status.rs`); the failure message is translated. Vietnamese display only (files unchanged): PivotTable date-group labels show as `Quý 1`, `Thg1`, `4-Thg1` in vi-VN (`pivot_labels.rs`; the cells and saved XLSX keep `Qtr1`, `Jan`), time formats show AM/PM as SA/CH in vi-VN and typing SA/CH reads back as a time, the column width and row height tips use the decimal comma, and the Cell Styles gallery and the undo list show Vietnamese names (the engine and files keep the English ones).
- Macro-enabled workbooks keep their VBA project (both, mostly web). Save and Ctrl+S keep the kind the workbook was opened as: an `.xlsm` downloads (web) or is written (desktop) as `.xlsm` with `xl/vbaProject.bin` unchanged byte for byte (`save_as.rs`, `io::workbook_ext`; `file.saveBytes` already took `xlsm`/`xltm`, and `xlsx` still leaves the project out). File › Save As and the desktop save picker offer "Excel Macro-Enabled Workbook (*.xlsm)" ("Sổ làm việc Excel có Macro") for a workbook with macros and start on it; saving such a workbook as `.xlsx` first asks "Save Without Macros?" ("Lưu mà không có macro?") with Save as .xlsm instead / Save anyway as .xlsx / Cancel (`io::drops_macros`; commands from agents and the control channel never ask). Web drafts and reopened closed documents of an `.xlsm` are written as `.xlsm` under that name and format (`drafts::draft_name`/`draft_format`, `io::save_xlsx_fast(wb, name)`), so a recovered draft still has its macros; the web bridge accepts `xlsx`, `xlsm` and `xltm` drafts. The info bar now says what happens ("GridCraft doesn't run them. Saving as .xlsm keeps them; saving as .xlsx removes them.") and the open warning about kept macros is translated. Macros are still never run.
- Close → Save waits for File System Access picker writes to finish before closing; cancelled or failed saves keep documents open, browser failures show a translated message, and Close / Close All wait for an existing write (web).
- A document close × in the narrow title bar uses the existing unsaved-changes flow and remains reachable at 390 px (both).
- The optional `window.erpEditorClosed()` hook is called once when a successful close leaves no documents, before the existing blank-workbook fallback (web).
